## 해결하려는 문제
Army TIGER+ 시범부대에는 많은 드론이 운용되지만 여전히 전용 물리 조종기로 조작합니다. 디스플레이 내장 조종기와 군용 GCS는 기체만큼 비싸고, 파손되면 수리비가 크며, 기종을 바꾸면 새로 사야 합니다. 부피가 크고 비행 전 바인딩·캘리브레이션이 복잡하며, 조종기 하나가 고장 나면 비행 중인 기체의 제어 수단이 사라집니다.

MotionCommand는 이미 가진 스마트폰·PC 카메라와 손 수신호로 드론을 통제하는 방식을 제안하고, 실기체 없이 3D 시뮬레이터로 먼저 훈련하게 합니다. 육군이 2026년 10월 공개한 Army TIGER+ 미래전 방향(50만 드론 전사 양성, 현장 기반의 변혁 TiC, 피지컬 AI 데이터 선순환)에 맞춘 소프트웨어 시제품입니다.

## 현장 활용 시나리오
1. **교육 전:** 훈련병이 개인 스마트폰으로 링크를 열고 ② 환경설정에서 카메라·권한을 자동 점검합니다. 수신호 카드와 매뉴얼 PDF로 9종을 익힙니다.
2. **훈련:** ③ 시뮬레이션에서 계급·이름을 입력하고 M1(기본 이착륙)부터 M4(종합 임무)까지 수행합니다. 왼쪽 화면은 손 관절 21점을, 오른쪽은 3D 드론과 미션 진행을 보여줍니다. 공중에서 전원을 끄려 하면 자동 착륙하고 실수로 기록합니다.
3. **사후검토:** 교관은 ④ 교관 탭에서 전원의 점수, 합격률, 실수 유형 분포를 한 화면에서 보고, 훈련자별로 "엄지척 단계에서 검지로 인식 3회" 같은 잘못된 습관과 교정 방법을 확인합니다. CSV로 내려받아 교육 결과 보고에 씁니다.
4. **확장:** 축적된 조작 데이터는 학습 기반 인식 고도화와 실기체 연동(보조·예비 통제 수단)의 근거 자료가 됩니다.

## 사용한 도구·기술
- **바이브코딩:** Claude (기획 인터뷰 → PRD 작성 → 구현·테스트)
- **손 인식 AI:** Google MediaPipe Hands (Tasks Vision 0.10.14), 브라우저 내 실행으로 영상 외부 전송 없음
- **제스처 분류:** 관절 21점 기하 규칙 기반 분류기(손가락 펴짐·방향·손 수평도), 유지 시간 필터, 신뢰도 임계값, Fail-safe(애매하면 정지)
- **3D:** Three.js 드론 시뮬레이터 (물리 보간, 경계, 자동 착륙, 배터리)
- **데이터:** Supabase(PostgreSQL + RLS)로 기록 공유, 미연결 시 기기 저장·CSV 대체
- **배포:** GitHub + Vercel, 빌드 없는 정적 사이트
- **검증:** 합성 손 좌표 11개 케이스로 분류기 단위 테스트, 브라우저 자동화로 미션 전 과정 시험

## 제작 후기
기능을 정하기 전에 배경·사용자·시나리오·데이터·화면·제약·완료 기준을 먼저 묻는 인터뷰로 PRD를 만들고 시작했습니다. 가장 어려운 부분은 "손바닥 아래로" 수신호였습니다. 정면 카메라로는 손바닥 방향을 구분하기 어려워, 손 전체가 수평으로 눕는 비율로 판정하도록 바꿨습니다. 동료 평가자 중 카메라가 없는 분도 체험할 수 있도록 화면 버튼·키보드 입력을 넣었고, 이 기능은 발표 현장에서 카메라가 말썽일 때의 백업도 됩니다. 2022년 전력/소요기획과정에서 시작한 Pose Estimation 관심사를 드론 통제로 확장할 수 있어 의미 있었습니다.

## 시연 체크리스트 (발표 전)
- [ ] 발표 PC 크롬에서 배포 주소 접속, 카메라 권한 허용
- [ ] ② 환경설정 7개 항목 초록색

- [ ] M1 한 번 리허설 → ④ 교관 탭에 기록 확인
- [ ] 카메라 실패 대비: 키보드 P · ↑ · ← · → · ↓ · O 순서 숙지
- [ ] 인식이 불안정하면 ③ "인식 보정"에서 신뢰도 0.6, 유지 배율 1.2로 조정
